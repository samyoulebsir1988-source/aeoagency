# Meridian

One-page site for an answer engine optimization practice. The name is a placeholder. Change `name` in [`lib/site.ts`](lib/site.ts) and the wordmark, titles, structured data, and footer all update.

The site offers two services: an AEO audit and AEO optimization. A free audit request form posts to `/api/audit-request`, which validates the submission and appends a row to a Google Sheet through an Apps Script web app.

## Develop

```bash
npm install
cp .env.example .env.local
```

Set `AUDIT_WEBHOOK_URL` in `.env.local` (see below), then:

```bash
npm run dev
```

`npm run build` produces the production build Vercel runs. No extra configuration is required.

## Environment

| Variable | Required | Purpose |
| --- | --- | --- |
| `AUDIT_WEBHOOK_URL` | Yes, for the form | The Apps Script web app `/exec` URL. The route returns a clear error when it is missing. |
| `NEXT_PUBLIC_SITE_URL` | No | Canonical origin for metadata, Open Graph, robots, and the sitemap, such as `https://www.example.com`. On Vercel, the production domain is used when this is unset. |

Redeploy after changing either variable. `NEXT_PUBLIC_SITE_URL` is read at build time.

## Google Sheet setup

The script is [`integrations/google-sheet/Code.gs`](integrations/google-sheet/Code.gs). It uses the sheet it is bound to. An empty first sheet receives a header row on the first submission.

1. Create a Google Sheet. Any name is fine, for example “Audit requests”.
2. Open **Extensions → Apps Script**.
3. Replace the contents of `Code.gs` with the file from this repo. Leave the Apps Script runtime on the default V8 runtime.
4. Select **Deploy → New deployment**.
5. Click the gear icon next to “Select type” and choose **Web app**.
6. Set **Execute as** to **Me**.
7. Set **Who has access** to **Anyone**. It must be reachable without a Google sign-in. “Anyone with a Google account” will reject the site’s server.
8. Click **Deploy**, then authorize the requested access to the spreadsheet.
9. Copy the **Web app URL**. It ends in `/exec`. Do not use the `/dev` URL.
10. In the Vercel project, open **Settings → Environment Variables** and set `AUDIT_WEBHOOK_URL` to that URL for Production (and Preview, if you want the form to work there).
11. Redeploy the site so the function picks up the variable.

Opening the `/exec` URL in a browser should show `{"ok":true,"service":"audit-requests"}`. That confirms the deployment. It does not write a row.

If you change the script later, deploy again as a **new version**. Apps Script pins the web app to the version you deployed; saving the editor does not update the live URL.

### What gets stored

Each submission appends:

| Received at | Name | Email | Website | Message | Submitted at |
| --- | --- | --- | --- | --- | --- |

`Received at` is the time the script runs. `Submitted at` is the ISO time the site sent. Values that start with `=`, `+`, `-`, or `@` are prefixed so Sheets does not treat them as formulas.

### Webhook contract

`POST` the JSON body below. `Content-Type` may be `application/json` or `text/plain`. The site sends `text/plain` because Apps Script web apps answer the first request with a redirect, and this content type matches that flow.

```json
{
  "name": "Ada Lovelace",
  "email": "ada@example.com",
  "website": "https://example.com/",
  "message": "Optional note",
  "submittedAt": "2026-11-22T04:00:00.000Z"
}
```

A saved row responds with:

```json
{ "ok": true }
```

`message` may be an empty string. The site follows redirects and treats the request as saved only when the final response is JSON with `"ok": true`.

## Form behavior

- Name, email, and website are required. Website may omit `https://`.
- Message is optional and limited to 2,000 characters.
- A hidden honeypot field (`hp_field`) is discarded as spam and is not written to the sheet. Those requests still receive a success response.
- Validation runs in the browser and again in the route.
- Missing `AUDIT_WEBHOOK_URL` returns HTTP 500 and the message “Audit requests are not configured. The server is missing AUDIT_WEBHOOK_URL.”
- A URL that is not https (other than localhost, for development) returns a clear configuration error.
- If the web app cannot be reached or does not return `{ "ok": true }`, the form shows an error and does not claim the request was saved.

## Pages and metadata

The marketing site is a single page: hero, problem, services, process, audit form, FAQ, and footer. `/robots.txt` and `/sitemap.xml` are generated by the App Router. The page includes Organization, ProfessionalService, WebSite, and FAQPage JSON-LD from the same FAQ copy shown on the page.
